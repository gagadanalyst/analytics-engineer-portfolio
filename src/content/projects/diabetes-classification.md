## Summary

This notebook investigates a public diabetes dataset, implements a simple K-Nearest Neighbours algorithm, compares it with scikit-learn, and explores the effects of scaling, feature selection and choosing the neighbour count.

## Scope and limitations

The existing notebook is an educational machine-learning exercise, not a clinical diagnostic tool. Preprocessing currently happens before the train/test split, and model selection uses test-set results; these issues need correction before its metrics should be relied upon.
